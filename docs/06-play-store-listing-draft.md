# MyChapter — Google Play 스토어 등록 문구 (초안)

> `docs/00-design-decisions.md`, `src/constants/projectTypes.ts` 기준으로 작성한 초안입니다.
> 실제 등록 전에 어조·강조 포인트를 원하는 대로 다듬어 사용하세요.

---

## 앱 제목 (최대 30자)

```
마이챕터 - 짧은 기록이 쌓여 한 권의 책이 되는 앱
```

대안 (더 짧게, 30자 제한 여유 있게):
```
마이챕터 - 기록이 책이 되는 앱
```

---

## 짧은 설명 (Short description, 최대 80자)

```
매일 2분, 질문에 답하듯 짧게 기록하면 AI가 챕터별로 엮어 책을 만들어줘요.
```

---

## 상세 설명 (Full description, 최대 4000자)

```
하루를 기록하고 싶은데, 무엇을 써야 할지 막막했던 적 있으신가요?
마이챕터는 매일 오늘의 질문에 짧게 답하는 것만으로 기록이 쌓이고,
그 기록들이 자동으로 한 권의 책으로 완성되는 기록 앱입니다.

■ 이렇게 사용해요
1. 나의 이야기 주제를 고르세요 (감정, 육아, 올해의 나, 퇴사와 도전, 직접 정의하기)
2. 매일 도착하는 오늘의 질문에 2분만 답해보세요
3. 질문형, 사진형, 자유일기형 중 편한 방식으로 기록하세요
4. 기록이 10개씩 쌓일 때마다 AI가 자동으로 챕터를 만들어드려요
5. 완성된 챕터를 다듬고, 표지를 골라 나만의 책으로 출판하세요

■ 마이챕터가 다른 점
- 백지의 부담이 없어요: 매일 새로운 질문이 기록의 첫 문장을 열어줍니다
- 쌓이는 게 눈에 보여요: 스트릭과 진행률로 얼마나 왔는지 확인할 수 있어요
- 기록이 결과물이 돼요: 흩어진 메모가 아니라, 챕터로 정리된 나만의 책이 됩니다

■ 이런 분께 추천해요
- 매일 감정을 기록하며 나를 돌아보고 싶은 분
- 아이의 성장 순간을 놓치지 않고 남기고 싶은 부모님
- 한 해를 마무리하며 연간 회고록을 만들고 싶은 분
- 퇴사, 이직, 창업 등 새로운 도전의 과정을 기록하고 싶은 분
- 나만의 주제로 자유롭게 기록을 시작하고 싶은 분

■ 주요 기능
- 오늘의 질문 자동 생성 (AI)
- 질문 답변 / 사진 기록 / 자유일기 3가지 기록 모드
- 기록 10개마다 자동 챕터 생성
- 챕터 원고 편집 및 재생성
- 표지 선택 후 PDF로 출판
- 매일 알림으로 기록 습관 만들기

지금 마이챕터와 함께, 오늘의 한 줄부터 시작해보세요.
```

---

## 릴리즈 노트 (최초 출시용)

```
마이챕터 첫 출시! 🎉

- 매일 오늘의 질문으로 시작하는 3가지 기록 모드 (질문 / 사진 / 자유일기)
- 기록이 쌓이면 AI가 자동으로 챕터를 만들어드려요
- 완성된 챕터를 책으로 편집하고 표지를 골라 PDF로 출판하세요
- 스트릭, 배지로 기록 습관을 확인하세요

여러분의 소중한 이야기가 한 권의 책이 되는 여정, 지금 시작해보세요.
```
