## 2. 컬러 (현행 유지 · 역할 명확화)

| 토큰 | 역할 | 사용 |
|------|------|------|
| Ink | 본문·제목 | 본문 기본 |
| Ivory / Paper | 면·배경 | 페이지 바탕 |
| Sage | 보조·성공·준비도 | 진행·완료 |
| Terracotta | Primary CTA | 버튼·강조 1개/화면 |
| Line / Hairline | 구분 | 카드 대신 규칙선 |

**금지(리뉴얼에서도):** 보라 그라데이션 기본 테마, 크림+세리프+테라코타 클리셰 복제, 다크모드 기본화.

---

## 3. 타이포

| 용도 | 방향 |
|------|------|
| Display / 책 제목 | 기존 Editorial serif 계열 유지·스케일 정리 |
| UI / 본문 | sans, 행간 여유 |
| 캡션 / PAGE | 한 단계 작게, 인용 톤 |

화면당 Display 헤드라인 **1개**. 브랜드명(MY CHAPTER)이 랜딩/온보딩 첫 뷰에서 약해지지 않게.

---

## 4. 레이아웃

- **Desk 홈:** 1 composition — CTA + 준비도 + PAGE. 통계 스트립·배지 과다 금지.  
- **서재:** 커버 그리드/선반. 카드 그림자 남용 금지 — 상호작용 필요할 때만 면.  
- **작업실:** 세로 섹션 + sticky 다음 행동.  
- **기록:** 원고대 — 상단 컨텍스트, 하단 저장.  
- 모바일 first; TabBar safe-area 유지.

---

## 5. 컴포넌트 체계 (초안)

| 컴포넌트 | 역할 | 유아이볼에서 가져올 패턴 |
|----------|------|-------------------------|
| `EmptyState` | 일러스트+한 줄+CTA 1 | Empty+CTA |
| `DeskProgress` | 준비도 요약 | 홈 위젯형 진행 |
| `BookShelfCard` | 서재 커버 | 선반·커버 초점 (스토어 X) |
| `StudioSection` | 작업실 블록 | 섹션 헤더+잠금 이유 |
| `StepperVisual` | 제작 단계 표시 | 다단계 진행 (로직 비침투) |
| `SuccessPanel` | 완료 다음 행동 | 성공+다음 CTA |
| `PaywallCompare` | Free/Pro | 대비 카드 (결제 불변) |
| `ConsentRow` | 동의 체크 | 항목 분리 (본문 승인 후) |
| `TabBar` | 3탭 | 활성 상태 명확 |

기존 shadcn/내부 컴포넌트와 **이름만 맞춰 점진 교체**.
